# Model Folder

This folder is reserved for the future small pretrained SLM and model metadata.

Do not commit large model binaries to GitHub. Store only:

- model choice notes
- download instructions
- license notes
- small config files

Candidate model families for later experimentation:

- TinyLlama
- SmolLM
- Qwen small models
- Gemma small models
- Phi small models

Final Android deployment should use a quantized local model, not a cloud API.
