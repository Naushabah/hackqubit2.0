# Evaluation Plan

This folder is for testing whether PathshalaAI answers are useful, safe, and curriculum-aligned.

Evaluation checklist:

- Answer stays within selected class.
- Answer stays within selected subject and chapter.
- Explanation is simple enough for a school student.
- The model admits uncertainty when the topic is missing.
- No cloud API is required.
- Android performance is acceptable after quantization.

Suggested metrics:

- curriculum relevance
- factual correctness
- answer clarity
- hallucination rate
- latency on target device
